# Schema Linking

- 语义相似度匹配；找到问题的答案最可能会在哪个表的哪一列里
- 遍历schema里所有表,计算表名相似度（问题 embedding 和表描述embedding）
- 对每个表计算问题和所有列名的相似度（问题embedding 和{列名+列描述}）

-----

# 问题

SQL无法处理：“我想要动力强一点但续航无所谓”

--> 使用 XML

- `<select></select>`: 代表需要查选的重要属性
- `<where></where>`: 代表过滤条件，采用 过滤属性名##过滤值##必要程度 组织，举例：车辆价格##\[10, 15\]##必要。
- `<order></order>`：代表排序条件，采用
	`排序属性名##排序类型##必要程度` 组织，举例：`百公里加速时间##ASC##必要`。
- `<group by></gourp by>`: 代表分组条件，运用于相同车系不同限制条件的场景
